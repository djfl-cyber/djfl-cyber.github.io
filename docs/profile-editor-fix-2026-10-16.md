# 关于页个人介绍编辑

原因：原来的“动态页面内容”只渲染页面插槽，设计器不能识别其中的个人介绍字段；该插槽还使用静态导入的站点资料，因此未保存草稿无法正确显示在卡片中。

将该卡片接入独立的个人介绍图层，静态页面和草稿使用同一渲染组件与同一份站点资料。右侧属性和弹窗可编辑作者名称、个人介绍正文、头像、GitHub 链接，头像可从素材库选择或导入，正文支持手动换行。草稿、撤销、保存、文件历史与版本冲突检查沿用现有机制。旧版 `about-content` 内容插槽仍兼容，不要求用户手动重做布局；复制页面或模板会保留可编辑图层。

操作：重启 Blog Studio，选择“页面设计 → 关于 → 个人介绍”（旧布局可能仍叫“动态页面内容”），在右侧直接修改，或点击“编辑个人介绍”后应用；按 Ctrl+S 保存，重新发布后更新线上博客。

姓名与头像是全站共用资料，个人介绍正文使用 `site.about`，与首页短简介 `site.authorBio` 分开。清空头像地址会恢复默认头像。未改动实际站点资料、文章或友链；没有提交、推送或部署。辅助脚本和验收副本分别位于 `scripts/studio/dev/` 与 `scripts/artifacts/`。
