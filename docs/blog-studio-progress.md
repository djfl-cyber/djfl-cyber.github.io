## 本轮补齐

- 自定义页面名称与网址管理；修改网址同时同步菜单，扁平化旧跳转。页面回收/恢复连同菜单与跳转处理；内置路由、大小写/中文冲突、已占用恢复位置均受检查。
- 未引用素材扫描与勾选回收，排除旧站原图、源码和本机恢复草稿。真正回收前再次检查引用与文件版本；外部新增引用会跳过，不永久批量删除。
- 页面切换、导航与关闭前保留最后一次草稿；设计器轮询磁盘版本并提供三方合并。改址/新建/回收/安装后刷新自有预览，修复 Astro 路由缓存导致的临时 404；普通设计保存不重启服务。
- 组件配置草稿恢复、独立字段合并与冲突逐项选择；版本默认配置入口。包先在私有区域验证，再整体进入公开组件目录。宿主在实例移除和页面退出时发送 destroy，并处理重新挂载。
- Windows 编辑器占用目录时，文章回收先留完整校验副本，再逐项移除；中途失败恢复已移除文件，剩余异常进入待复核事务。恢复不覆盖已有内容。
- 博客内容备份与本机草稿/模板/历史备份分开；私有备份排除身份、浏览器配置、日志及递归备份。选择恢复有哈希与磁盘版本复核。
- 文章列表封面与本地变更标记；VS Code 项目入口、便携程序开发依赖准备按钮、界面细节与组件规范说明。
