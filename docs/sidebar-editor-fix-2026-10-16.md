# 首页侧栏内容编辑

原来的侧栏图层有外观属性，但没有注册内容字段，无法在画布右侧或编辑弹窗修改。现在接入统一组件编辑器，并使用同一份设置保存和预览。

可编辑作者名称、作者简介、头像、作者状态、开始写作年份、文章数量单位、写作年份说明、关于入口文字、归档眉题、归档标题、便笺标题、正文与角标。作者简介和“关于”页正文分别使用 `site.authorBio` 与 `site.about`，不会相互覆盖；姓名、头像与开始年份为全站共用。文章总数、归档月份和月度篇数继续由文章自动生成。

重启 Blog Studio 后，在“页面设计 → 首页”选择“侧栏”，可直接修改右侧字段，或点击“编辑侧栏”打开分组表单。头像可从素材库导入。弹窗中先应用到画布，再按 Ctrl+S 保存。作者简介、便笺和其他文字均保留换行；隐藏区域的字段仍可填写。

开始写作年份保存为整数，仅为组件明确注册的数字字段开放数字保存；其他文字绑定保留原有类型限制。保存覆盖站点、首页和文字三个配置分组，沿用版本冲突检查、文件历史、草稿与撤销机制，无关字段保持。

本轮未修改实际作者资料、首页文案、友链或文章，没有提交、推送或部署。实现和辅助脚本位于 `scripts/studio/` 及其 `dev/` 子目录，验收与便携文件位于 `scripts/artifacts/`。
