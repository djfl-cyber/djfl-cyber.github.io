# 文字换行与设计预览一致性修复

日期：2026-10-16。本轮以 `e3d1fa1687e5609c9e9776442a540ec026b6d45a` 为起点，只处理文字换行、文字框高度和设计预览一致性；不同设备独立编辑暂未改动。未提交、推送或部署。

## 问题与修改

1. 配置中的换行存在，但普通 HTML 文本会折叠它。新增共用文字渲染组件，将真实换行输出为安全的 `<br>`，并保留空格、允许长文字在框内换行。适用于普通文字、链接和页头页脚的已接入文字，不将用户输入当作 HTML 执行。
2. 标题拖动后保存了固定 `width` 和 `height`，字体随视口变化时，文字可能超过高度并盖住按钮。文字默认按内容增高，原 `height` 作为最小高度；固定文字框可显式选择。拖动中的临时预览使用同样规则。正常流式排版会为增高文字留出位置，自由画布的其他绝对定位元素不会自动重排。
3. 草稿与保存状态没有明确区分，开发模式还会列出草稿文章。增加“草稿预览 / 已保存效果”，后者只读且读取磁盘内容；文章列表默认只含已发布文章，“包含草稿文章”需显式勾选。
4. 画布宽度与浏览器不同，响应式字号和换行自然不同。增加清晰的页面宽度输入与“屏幕宽度”入口，说明页面宽度与画布缩放的区别。

私有预览通过验证过的本机会话及每请求上下文区分草稿、保存状态和文章可见性。避免依赖 Astro 静态页面会丢弃的请求头，也避免多个请求互相污染。普通本地浏览地址不再套用当前设计草稿。发布构建使用无管理端依赖的空预览模块，保持静态博客独立。
