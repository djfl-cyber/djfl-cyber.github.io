# 友链与导航的页面内管理

友链和导航由不可编辑的页面插槽改为有明确数据源的列表图层，使用同一个访客组件渲染正式页面和本地草稿。数据继续保存在 `src/data/friends.json` 和 `src/data/navigation.json`，原网址保持，现有设置入口也可继续使用。

## 操作

1. 打开 Blog Studio → 页面设计 → 友链 / 导航。
2. 在画布上方点击“新增友链 / 新增导航”。已有条目通过“管理条目”进入，选中列表图层后右侧也提供入口。
3. 填写名称、网站链接、介绍和分类。头像 / 图标可从素材库选择、导入，也可填写图片网址。未填图片时显示名称首字。
4. 在条目列表中选择、修改、上移、下移、隐藏；删除需在编辑框确认。
5. 点击“应用到画布”，检查草稿；支持撤销、重做。再按 Ctrl+S 保存，正式发布仍需进入发布流程。

取消未应用表单不会改动条目；已导入图片仍保留在素材库。关闭程序前先应用希望保留的表单内容。

## 同类模板

插入工具的“内容列表”可将友链或导航放入其他页面，复制模板时保留列表数据源。同源列表共用内容；同一页面多个导航列表的搜索和分类筛选互不干扰。列表定义集中在 `src/lib/directory-model.mjs`，新增同类数据源时注册名称、图片字段名称和分组模式，同时补充配置校验、项目配置路径及页面文案，即可复用编辑器与访客组件。

旧版友链 / 导航内容插槽仍兼容识别，恢复旧布局也能进入列表管理。保存只接受当前布局声明的数据源，沿用原有版本检查和文件历史，不会顺带覆盖其他设置。
