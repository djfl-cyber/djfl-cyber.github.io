# 文字工作台迁移与清理记录

更新：2026-10-16。原浏览器文字工作台已退役，统一使用本机 Blog Studio。没有提交、推送或部署；线上博客需在后续获准发布时更新。

## 功能核对

逐项核对旧工作台的 5 组 93 个文字字段，均可通过管理程序保存，保留原链接与布局信息。

| 原有文字 | 字段数 | 管理程序入口 |
| --- | ---: | --- |
| 首页文字 | 11 | 设置 → 首页内容 |
| 菜单文字 | 5 | 设置 → 顶部导航 |
| 站点与作者文字 | 6 | 设置 → 站点与作者 |
| 各页面介绍 | 21 | 设置 → 页面介绍 |
| 通用组件文字 | 50 | 设置 → 组件文字 |

| 原工作台能力 | 迁移后的操作 |
| --- | --- |
| 查找字段与文字 | 设置页“查找本组设置”，按标签、当前文字及嵌套字段筛选；支持清除 |
| 修改并保存 | 表单编辑后点击“保存”，或按 Ctrl/Cmd+S |
| 撤销本组未保存修改 | “撤销本组修改”，重新读取磁盘版本并清除本组草稿 |
| 切换分组保留未保存内容 | 自动私有草稿；再次进入可选择继续编辑 |
| 同屏观察博客 | “效果预览”打开侧边预览，可切换首页、文章、内置和自定义页面 |
| 刷新与完整浏览器预览 | 预览栏“刷新”“浏览器打开 ↗”；保存设置后自动刷新 |
| 保存前备份与冲突检查 | 管理程序文件历史、保存版本检查、冲突合并与恢复 |
| 旧文字备份 | 设置 → 项目与工具 → 维护与备份 → 本地备份 |

同屏预览显示已保存内容，与实际 Astro 页面共用渲染器。所有写入仍通过本机管理程序完成。

发布检查中的退役 URL 阻断规则、回归测试和 Git 忽略规则继续保留，防止旧入口或本机管理代码被重新发布。这些规则不会创建网页、服务器或写入接口。历史方案及清理审计保留文字说明。
